# 함정 경하중량 회귀분석

## Windows 실행파일 다운로드

[Naval Ship Weight Estimator.exe 다운로드](https://github.com/21227386/regression-analysis/raw/refs/heads/main/downloads/Naval%20Ship%20Weight%20Estimator.exe) — 약 100MB

다운로드 후 EXE를 더블클릭하세요. Python 설치나 수동 압축 해제 없이 첫 실행 시 필요한 파일을 자동으로 준비합니다. Windows 10/11 64비트용입니다.

최신 버전은 순항속력(kn) 입력을 사용하며 kn은 knot(노트)와 같은 의미의 표기입니다. 실제 Windows PC에서의 최종 실행은 사용자가 확인할 예정입니다.

업로드된 식 `W_LS = K (L B H)^α V^β D_T`의 계수를 실적선 자료로 추정하는 Streamlit 프로그램입니다.

## 실행

```bash
cd /workspace/regression-analysis
python -m venv /workspace/venvs/regression-analysis
/workspace/venvs/regression-analysis/bin/pip install -r requirements.lock.txt
/workspace/venvs/regression-analysis/bin/streamlit run app.py --server.address 0.0.0.0
```

입력은 Excel `.xlsx`입니다. 첫 행에 `함종,경하중량,길이,폭,깊이,순항속력` 열 이름을 입력하세요. `함명`은 선택 항목이며 생략하면 자동 번호를 부여합니다. 단위는 tonne, m, kn입니다. 여러 시트가 있으면 자료 시트를 선택할 수 있고 완전히 빈 행은 제외합니다. 화면에서 빈 엑셀 양식 또는 가상 예제를 다운로드하고 표를 편집할 수 있습니다. 함종은 `구축함`, `호위함`, `고속함`, `지원함`, `상륙함`, `기뢰전함`만 허용합니다. 예제는 고정 시드로 만든 가상 자료이며 실제 함정 자료가 아닙니다.

## 해석

- 1단계: 호위함 자료만 로그 변환 최소제곱에 사용하여 K, α, β를 추정합니다. 2단계: 이 계수를 고정하고 다른 함종의 D_T를 산출합니다. D_T는 해당 함종의 `실적중량 / [S K (LBH)^α V^β]` 비율의 기하평균입니다. K와 D_T는 곱만 식별되므로 기준 함종인 **호위함의 D_T를 1로 고정**합니다. 호위함 자료가 반드시 필요하며, 자료가 없는 다른 함종의 계수는 추정하지 않습니다.
- 입력은 모두 유한한 양수여야 합니다. 호위함 자료가 최소 4척 필요하고 호위함 내에서 독립적인 크기·속력 변화가 있어야 합니다. 다른 함종의 자료로 이 조건을 대체할 수 없습니다. 자료 개수 조건만으로 신뢰성이 보장되지는 않습니다.
- 기본값은 로그 공간 적합값을 지수 변환합니다. 호위함 잔차에서 산출하는 선택적인 Duan smearing 보정을 켜면 최종 식은 `W = S K (LBH)^α V^β D_T`입니다. 내보낸 계수 CSV에 S를 포함합니다.
- 실적선별 예측, 부호 있는 오차, 오차율, MAE/RMSE/MAPE 및 중량 공간 R²를 제공합니다. 오차는 예측−실적입니다. 표시된 지표는 학습 자료의 적합 오차이며 독립 검증 성능이 아닙니다.
- 새 함정 추정은 학습된 함종에 대해 제공하며 자료 범위를 벗어나면 경고합니다. 예측구간 및 교차검증은 포함하지 않습니다. 함종당 자료가 적거나 공선성이 높으면 계수 해석에 주의하세요.
- 외부 API, 인증정보, 데이터베이스는 필요하지 않습니다. 업로드 자료는 프로그램이 파일로 저장하지 않습니다. 민감한 자료를 다룰 때에는 실행 서버의 접근 권한을 별도로 관리하세요.

## 검증

알려진 계수 복원, 다른 함종 자료가 호위함 계수를 바꾸지 않는지, 함종별 비율의 기하평균 계산, 입력 오류/식별 불가 자료 거부, 보정과 오차 계산을 확인합니다.

## 3차원 곡면

선택 함종의 D_T를 고정하고 X축 LBH(m³), Y축 순항속력(kn), Z축 경하중량(tonne)의 회전 가능한 곡면을 표시합니다. 원래 식은 일반적으로 곡면이며 로그 공간 보기에서는 평면입니다. 보정이 켜져 있으면 S도 반영합니다. 실적 중량과 예측 중량을 점으로 표시하고 차이를 수직선으로 연결합니다. 선택 함종의 관측 범위를 사용하되 관측이 드문 조합의 신뢰성을 보장하지는 않습니다. 그래프는 인터넷 연결 없이 열 수 있는 HTML로 다운로드할 수 있습니다.

## 실적선 추가와 재학습

기존 자료와 새 자료를 합친 엑셀을 업로드하거나 표에 행을 추가하면 전체 자료로 다시 추정합니다. 현재 학습자료 엑셀 저장 버튼으로 수정한 자료를 내려받아 다음 분석에 재사용하세요. 서버에 자동 누적 저장하지 않습니다. 중복 자료는 의도치 않은 가중치가 되므로 확인해야 합니다.

호위함 자료가 추가되면 K, α, β를 재추정하고 모든 D_T를 다시 계산합니다. 다른 함종 자료만 추가하면 호위함 계수는 유지되고 해당 함종 D_T가 갱신됩니다. 데이터 증가는 정확도 향상을 보장하지 않습니다. 단위 일관성, 경하중량 정의, 자료 품질 및 크기·속력 범위가 중요하며, 실제 예측 성능 개선 여부는 학습에 사용하지 않은 실적선으로 확인해야 합니다.

## 순항속력 사용

V는 최대속력이 아닌 순항속력(kn)입니다. 기존 최대속력 열은 자동으로 이름을 바꾸거나 환산하지 않습니다. 함정별 실제 순항속력 자료를 입력하고 계수를 다시 추정하세요. 최대속력 기반 계수와 혼용하지 마세요. 사용자 제공 순항속력 참고 범위는 구축함 17–20, 호위함 15–18, 고속함 15–20, 지원함 12–15 kn이며 확정된 환산비가 아닙니다.

## 단일 Windows EXE 배포

화면의 kn 표기는 knot(노트)와 같은 의미이며 수치 변환은 없습니다. Excel 양식의 속력 열은 순항속력 (kn)로 표시하며 순항속력 열 이름도 계속 지원합니다. 단일 EXE는 첫 실행 시 포함된 Python과 라이브러리를 사용자 LocalAppData의 ShipRegression 폴더에 자동으로 풀어 실행합니다. 설치할 Python이나 인터넷 연결이 필요하지 않습니다. 첫 실행에는 약 512MB의 여유 공간이 필요합니다. v2 실행기는 내장 ZIP 추출기를 사용하므로 PowerShell이 필요하지 않습니다. 이후에는 준비된 파일을 재사용합니다.

## Windows 실행기 v2 (파일 준비 단계 개선)

기존 `Preparing application files. Please wait...` 단계에서 사용하던 PowerShell 호출을 제거했습니다. EXE 안의 ZIP 추출기가 직접 파일을 풀고 CRC를 확인하며 진행률을 표시합니다. 새 캐시 `%LOCALAPPDATA%/NavalShipWeightEstimator/CruiseNot_v2`를 사용하므로 이전 캐시를 직접 삭제할 필요가 없습니다. 실패하면 단계·종료코드와 로그 경로를 오류창에 표시합니다. `startup.log`는 실행기, `runtime.log`는 Python 서버 기록입니다.

Wine 10.0에서 새 EXE의 첫 실행, 9,696개 파일 추출 및 CRC/크기 일치, 서버 응답, 두 번째 실행의 캐시 재사용을 확인했습니다. 실제 Windows PC에서의 검증은 아직 이루어지지 않았습니다.
