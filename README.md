# Naval Ship Weight Estimator

Windows 데스크톱 GUI에서 실적함 엑셀로 회귀계수를 산출하고, 새 함정의 제원으로 경하중량을 추정합니다. Python 설치·브라우저·웹서버가 필요하지 않은 EXE를 제공합니다.

[Windows 실행파일 다운로드](https://github.com/21227386/regression-analysis/raw/refs/heads/main/downloads/Naval%20Ship%20Weight%20Estimator.exe)

## 사용 순서

1. EXE를 실행하고 **Download Input File Template**을 누릅니다.
2. Excel에서 실적함 자료를 작성합니다. 필수 열은 `함종, 경하중량, 길이, 폭, 깊이, 순항속력 (kn)`입니다. `함명`은 선택입니다. 단위는 tonne, m, kn이며 kn은 knot(노트)와 같은 의미입니다.
3. **Input File Upload**를 누르면 계수가 자동으로 계산됩니다. 여러 시트가 있으면 자료 시트를 선택합니다.
4. **회귀계수·실적 비교**에서 K, α, β, 함종별 D_T와 적합 오차를 확인합니다.
5. **설계 함정 중량 추정**에서 함종·길이·폭·깊이·순항속력을 입력합니다. 설계 함정의 중량을 입력할 필요는 없습니다.
6. **그래프·3차원 곡면**에서 실적과 예측의 비교, 함종별 곡면과 로그 평면을 확인합니다. 그래프 도구모음에서 이미지를 저장할 수 있습니다.

함종은 구축함·호위함·고속함·지원함·상륙함입니다. 최대속력 자료를 순항속력으로 자동 환산하지 않습니다. 깊이는 흘수와 구분하세요.

## 추정 방식과 한계

`W = K × (L×B×H)^α × Vc^β × D_T`

전체 함종의 자료로 `ln(W) = ln(K) + α ln(LBH) + β ln(Vc) + Σ γ_t I(함종=t)`를 한 번에 최소제곱 추정합니다. 지원함은 기준으로 D_T=1을 고정하고 다른 함종은 D_T=exp(γ_t)로 구합니다. 각 실적함에 같은 가중치를 주므로 척수가 많은 함종이 더 많이 반영됩니다. 기준은 K와 D_T의 표현 척도를 정하며, 동일 자료에서 기준만 바꾸면 예측값은 같습니다. 데스크톱에는 로그 역변환 편향 보정을 적용하지 않습니다.

지원함 자료가 포함되어야 합니다. 입력에 나타난 함종 수를 m이라 하면 추정계수는 m+2개이며 전체 자료는 최소 m+3척이 필요합니다(5개 함종은 8척 이상). 다른 함종은 1척도 참여 가능하지만 해당 설계계수의 신뢰성은 제한됩니다. 단순 척수뿐 아니라 함종 내 크기·속력에 독립적인 변화가 있어야 합니다. 함종 효과와 크기·속력 효과가 구분되지 않으면 추정을 중단합니다. 화면과 보고서에 추정계수 수와 잔차 자유도를 표시합니다. 자료가 없는 함종의 계수는 추정하지 않습니다. 과거 모형은 새 자료로 적합할 수 없을 때 재사용하지 않습니다. 자료 수 증가만으로 예측 정확도 향상이 보장되지는 않습니다. 표시되는 MAE·RMSE·MAPE·R²는 학습 자료의 적합 지표이며 독립 검증 성능이나 예측구간은 아닙니다.

처음에는 실제 자료 없이 빈 화면으로 시작합니다. **가상 예제 보기**는 기능 확인용이며 실제 설계에 사용할 수치가 아닙니다.

## 추가 자료와 저장

**Input File Upload**로 업데이트한 실적함 Excel 파일 전체를 업로드하세요. 새 파일이 기존 입력자료를 교체하고 전체 자료로 다시 학습합니다. 자료 추가 버튼은 제공하지 않습니다. **입력자료 저장**으로 현재 자료를 Excel에 저장할 수 있습니다. 자동 누적 저장은 하지 않습니다.

**계수·실적 비교 엑셀 저장**은 입력자료, 회귀계수, 함종별 D_T, 실적함 비교, 적합 지표의 5개 시트를 저장합니다.

## Windows 실행

Windows 10/11 64비트용입니다. 첫 실행에서 필요한 파일을 사용자 LocalAppData에 자동 준비하고, 다음 실행부터 재사용합니다. PowerShell이나 Python 설치, 인터넷 연결, 웹서버가 필요하지 않습니다. 약 512MB 이상의 디스크 여유 공간을 확보하세요.

새 버전의 캐시는 `%LOCALAPPDATA%/NavalShipWeightEstimator/Desktop_v8`입니다. 실행 오류 시 이 폴더의 `startup.log`, `runtime.log`를 확인하세요. 이전 버전 캐시를 직접 지울 필요는 없습니다.

## 소스로 실행

Windows Python 3.12에서:

```bat
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements-desktop-lock.txt
.venv\Scripts\python desktop_app.py
```

`workflow.py`는 자료 불러오기·재학습·예측·결과 저장을 담당하고, `desktop_app.py`는 Windows 네이티브 GUI입니다. `packaging/desktop_launcher.c`는 단일 EXE에서 내장 ZIP을 준비하고 GUI를 실행합니다. 라이선스는 각 런타임/라이브러리와 `packaging/vendor/miniz/LICENSE`, `assets/fonts/OFL.txt`를 참고하세요.

회귀·엑셀·워크플로 테스트 18개가 통과했습니다. Wine 10.0에서 실제 Windows용 GUI의 엑셀 읽기·자동 학습·예측·입력 파일 교체·결과 저장·3D/로그 그래프 동작을 확인했고, 단일 EXE의 첫 파일 준비와 창 열림도 확인했습니다. Windows 호환 환경(Wine)의 검증은 실제 Windows PC 검증과 구분합니다. 이전 브라우저 버전의 설명은 [docs/LEGACY_WEB.md](docs/LEGACY_WEB.md)에 있습니다.

## GUI 표시

좌측 메뉴는 굵은 글씨로 표시하며 버튼은 그라데이션·그림자·눌림 효과를 제공합니다. 상단의 함정·중량 계측 일러스트와 Regression Model의 수식 이미지는 프로그램에 포함되어 오프라인으로 표시됩니다. 오른쪽 아래에는 `Copyright by Naval Ship Design Technology Division`을 표시합니다. 로그 역변환 편향 보정 선택 및 S 표시는 제공하지 않으며 결과 Excel에도 S를 내보내지 않습니다.

## 기호와 영문 글꼴

K, alpha, beta 및 D_T 표시는 수학 기호 이미지로 제공하고 한글 설명은 괄호 안에 표시합니다. 영문에는 Windows에 설치된 Times New Roman을 우선 사용하고, 한글에는 NanumGothic 보조 글꼴을 사용합니다. Times New Roman을 재배포하지 않으며 해당 글꼴이 없는 환경에서는 사용 가능한 세리프 글꼴로 대체합니다. 수식 이미지는 Times 계열과 어울리는 STIX 수학 글꼴로 조판합니다. 검증용 Wine 환경에는 Times New Roman이 설치되어 있지 않아 해당 글꼴 자체의 실제 렌더링은 미검증이며, 대체 세리프 글꼴로 기능·배치를 확인했습니다. 상단 함정 일러스트는 이전 대비 약 45% 확대하고 배경 카드로 강조했습니다.

### v6 비교 화면

제품명에서 N/W를 제거하고 Naval Ship Weight Estimator를 강조했습니다. 실적 중량 비교의 선택 상자에서 전체 함종과 개별 함종의 결과 및 MAE, RMSE, MAPE, R²를 확인할 수 있습니다. 각 지표의 영문명과 한글 설명을 표시하며, 선택은 조회 범위만 바꿉니다. Excel 보고서의 학습자료_적합지표 시트에도 전체 및 함종별 결과가 저장됩니다. R²는 1척 또는 실적 중량이 일정한 경우 산출 불가로 표시합니다. 비교 영역은 작은 화면에서도 스크롤하여 확인할 수 있습니다.

### v7 전체 함종 동시 추정

지원함 다수, 구축함 4척, 호위함 3척의 구성도 동시 추정에 사용할 수 있습니다. 특정 함종만으로 공통 회귀계수를 구하던 기존 방식은 사용하지 않습니다. 어느 함종의 자료든 업데이트하면 모든 계수를 다시 추정합니다.

동시 모형은 함종 사이에 크기 지수와 속력 지수가 공통이고 함종 차이는 배율 D_T로 표현된다고 가정합니다. 자료가 많은 지원함의 특성이 공통 지수에 더 많이 반영될 수 있으므로 전체 지표와 함종별 지표를 함께 확인하세요.

### v8 단위 표기 및 상륙함

속력 단위 표기는 kn(노트)로 통일했습니다. 수치 환산은 없습니다. 기존 순항속력 (not), 순항속력 (knot) 열도 계속 불러올 수 있습니다. 상륙함을 Excel 선택 목록, 예제, 공통 회귀 및 설계계수 추정, 예측, 전체/함종별 비교, 3D 그래프와 보고서에 추가했습니다. 상륙함의 예제 속력은 가상 자료이며 권장 속력이나 환산비가 아닙니다.
